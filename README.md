# 🌿 Roots2Routes
> **Smart Tourism Load-Balancing & Local Economy Empowerment Platform for Chhattisgarh**

Roots2Routes is a modern web application designed to tackle overcrowding at major tourist hotspots in Chhattisgarh (such as Bastar and Surguja) by intelligently balancing visitor traffic, promoting offbeat locations, and directly supporting local tribal artisans and rural homestay hosts.

## ✨ Key Features

* **📊 Live Crowd Telemetry & Capacity Balancer:** Real-time monitoring of footfall indices and crowd density at popular destinations to prevent overcrowding.
* **🗺️ In-App Trip Planner:** An intelligent step-by-step routing tool that suggests alternative lower-capacity destinations when major hotspots reach peak capacity.
* **💬 WhatsApp Travel Assistant:** An integrated conversational assistant widget allowing tourists and local guides to query live capacities directly in Hindi or English.
* **🧵 Local Artisan & Handloom Marketplace:** Direct digital showcase for authentic Chhattisgarh crafts (e.g., Bastar Dokra figurines and Champa Kosa silk) to boost rural micro-economies.
* **🌓 Global Dark/Light Mode:** Seamless custom theme toggling built directly into the navigation layout for optimal viewing comfort.
* **⚡ Modern UI Polish:** Designed with responsive micro-grids, smooth transitions, and loading skeleton shimmer animations for an enhanced user experience during API fetches.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, Modern CSS3 (Flexbox/Grid, Custom Properties), Vanilla JavaScript (ES6+).
* **Backend Integration:** RESTful API endpoints hosted on `railway.app`.
* **Styling & Aesthetics:** Deep forest green dark mode aesthetic (`#0b1a0e`) matched with emerald and amber accents.
* **Version Control:** Git & GitHub.

## 🚀 Getting Started

To run a local copy of this project on your machine, follow these simple steps:

1. **Clone the Repository:**
   ```bash

   ```
2. **Navigate to the Project Directory:**
